👀 中身を見る ― キャラの動きのプログラム
// キャラの動きを決めるプログラム（本物と同じ仕組み）
const physics = {
  gravity:   0.6,  // 重力：落ちる速さの増え方
  jumpPower: 12,   // ジャンプの初速
  walkSpeed: 3     // 歩く速さ
};

let velocityY = 0;  // いまの上下方向の速さ

function update() {
  // ① 重力：毎フレーム、落ちる速さが増える
  velocityY -= physics.gravity;
  chara.y += velocityY;

  // ② 地面やブロックに着いたら止まる
  if (chara.y <= floorY) {
    chara.y = floorY;
    velocityY = 0;
  }

  // ③ ジャンプ：地面にいるときだけ跳べる
  if (jumpPressed && onGround) {
    velocityY = physics.jumpPower;
  }

  // ④ 歩く：向き × 速さ のぶん進む
  chara.x += direction * physics.walkSpeed;

  // ⑤ 星：当たったら取る（+100ポイント）
  if (hitStar) {
    score += 100;
  }
}
ルールは数字
いちばん上の3つの数字が、このゲームの「ルール」です。右のパネルで変えているのは、まさにこの数字。数字を変えると、動きがその場で変わります。
① 重力
1フレームごとに、落ちる速さが gravity のぶん増えます。だから落ち始めはゆっくり、だんだん速くなります。数字を大きくすると「重ーい」落ち方に、小さくすると月面みたいにふわりと落ちます。
② 止まる判定
地面やブロックの高さまで来たら、そこで止まります。この判定があるから、ブロックの上に乗ったり、段差をおりたりできます。
③ ジャンプ
地面に足がついているときだけ、jumpPower の勢いをもらって跳び上がります。空中では跳べません。
④ 歩く
1フレームに walkSpeed のぶんだけ、向いている方向へ進みます。数字が大きいほど速く歩きます。
⑤ 星を取る
キャラと星が重なったら星を取り、ポイントが100増えます。高いところの星は、ジャンプの強さを大きくしないと届きません。

プログラムは見せるだけ（読み取り専用）。右のパネルで数字を変えると、プログラムの数字もその場で変わって、光ります。

⚙️ 動きの設定

数字を変えると、キャラの動きがすぐに変わるよ。これが「プログラムを変える」ということ。
